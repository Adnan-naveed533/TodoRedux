# TodoRedux 📝

A simple and interactive Todo application built with **React** and **Redux Toolkit** for efficient global state management. This project demonstrates full CRUD (Create, Read, Update, Delete) functionality with a clean, modern UI styled using **Tailwind CSS**.

## 🚀 Features

- ✅ **Add Todos** – Quickly add new tasks to your list
- ✏️ **Edit Todos** – Update existing todos inline without page reload
- 🗑️ **Delete Todos** – Remove tasks you no longer need
- 🎨 **Modern UI** – Clean design with hover effects and smooth transitions
- ⚡ **State Management** – Powered by Redux Toolkit for predictable state updates

## 🛠️ Tech Stack

- **React.js** – Frontend library for building the user interface
- **Redux Toolkit** – For managing global application state
- **React Redux** – Official React bindings for Redux
- **Tailwind CSS** – For styling and responsive design

## 📦 Installation

1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/TodoRedux.git
```

2. Navigate to the project folder
```bash
cd TodoRedux
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```
